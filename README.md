# Portafolio Web

Este es mi portafolio personal desarrollado con **React**, **TypeScript** y **Vite**. Aquí presento mis proyectos, habilidades y experiencia en desarrollo web.

---

## 🚀 Tecnologías Utilizadas

- **React:** Biblioteca para construir interfaces de usuario interactivas.
- **TypeScript:** Superset de JavaScript que mejora la seguridad y escalabilidad del código.
- **Vite:** Herramienta de construcción rápida y eficiente para proyectos de React.
- **TailwindCSS:** Framework de diseño para estilos rápidos y responsivos.
- **ESLint & Prettier:** Para mantener un código limpio y consistente.

---

## 📦 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repo.git
   cd tu-repo
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el proyecto en modo desarrollo:
   ```bash
   npm run dev
   ```
